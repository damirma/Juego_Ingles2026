The Case of the Missing Debate Trophy

Open the case file

Enter a name for each detective team (2 to 4 teams). Then start the investigation.

How to play (rules)
  1. Split the class into 2–4 detective teams.
  2. Read the case introduction and the list of suspects out loud.
  3. Read each grammar clue out loud, one at a time, in order.
  4. Teams try to answer using the correct grammar. Press "Reveal Answer" to check.
  5. Award the point to the team that answered correctly (or press "No one got it" — the clue unlocks either way, so the case keeps moving).
  6. Press "Next Clue" to continue. Each suspect has 2 clues — once both are revealed, watch the Suspects panel: that suspect turns ✅ Cleared or ⚠️ Suspicious.
  7. When all 8 clues are unlocked, only one suspect should still be ⚠️ Suspicious. Click that suspect's card to close the case.
  8. The team that solves the case correctly wins 300 bonus points — but everyone can guess!
